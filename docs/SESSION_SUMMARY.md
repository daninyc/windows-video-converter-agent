## 1. 原题与岗位背景

笔试要求使用 AI 开发视频格式转换器：显示视频信息和缩略图，允许调用 FFmpeg 命令行，自行优化，保留会话总结和开发者选择/反馈，提交 GitHub 项目；界面需要体现客户端开发，作品要能给实际使用者操作并经过测试。

岗位图片强调 Windows 桌面应用、界面开发、调试打包、AI 工具和 Agent/RAG 等能力。用户明确首版只做 Windows。岗位列出的框架作为选型参考，不据此编造面试官对某一框架的排名。

用户要求先进行逐轮需求确认，问题带编号、短标题、A/B/C 选项、推荐理由；前置条件未明确时不问后续技术细节，事实由开发代理查证。需求阶段禁止编写实现。开发者主要背景为 Python，最终采用 Python＋PySide6＋Qt Widgets。

交付期限由用户指定为北京时间 10月23日 12:00 前；结合当前会话年份，Spec 记为 2026-10-23。没有把最初“三天”重新计时。
